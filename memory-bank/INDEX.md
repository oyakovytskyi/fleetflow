# Memory Bank Index

Read these at the start of every significant session (in order):

1. `activeContext.md` — what we are doing now
2. `progress.md` — done vs remaining
3. `projectbrief.md` — scope / non-goals
4. `systemPatterns.md` — architecture decisions
5. `techContext.md` — stack and constraints
6. `productContext.md` — user flows / UX

After completing a feature or changing architecture, update `activeContext.md` and `progress.md`. Update `systemPatterns.md` when a decision changes.
